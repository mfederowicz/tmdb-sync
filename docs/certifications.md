# `certifications`

Movie and TV certifications by country.

| action  | example                                    | output file                    |
|---------|---------------------------------------------|----------------------------------|
| `movie` | `tmdb-sync certifications -a movie`        | `certifications_movie.json`      |
| `tv`    | `tmdb-sync certifications -a tv`           | `certifications_tv.json`         |

`cert` is the module's `Abbrev` — `tmdb-sync cert -a movie` also works.
