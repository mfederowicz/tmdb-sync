# `credits`

Credit details.

| action    | example                                                        | output file                                              |
|-----------|-----------------------------------------------------------------|------------------------------------------------------------|
| `details` | `tmdb-sync credits -a details -i 52542282760ee313280017f9`    | `credits_details_id-52542282760ee313280017f9.json`       |

Notes:
- `-i <credit_id>` is required.
- `cr` is the module's `Abbrev` — `tmdb-sync cr -a details -i 52542282760ee313280017f9` also works.
