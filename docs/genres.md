# `genres`

TMDB's official genre lists for movies and TV shows.

| action  | example                       | output file           |
|---------|-------------------------------|------------------------|
| `movie` | `tmdb-sync genres -a movie`   | `genres_movie.json`    |
| `tv`    | `tmdb-sync genres -a tv`      | `genres_tv.json`       |

`genre` is the module's `Abbrev` — `tmdb-sync genre -a movie` also works.
